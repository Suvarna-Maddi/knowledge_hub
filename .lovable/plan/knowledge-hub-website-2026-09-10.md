# Knowledge Hub Website

## Overview
Build a complete, responsive six-page website for Knowledge Hub in Suncity, using the supplied navy, white, and blue visual system with Poppins headings and Inter body text.

## Pages and content
- Create Home, About, Courses, Testimonials, Gallery, and Contact pages with unique page titles and descriptions.
- Add a shared sticky navigation bar, mobile menu, Join Now action, and structured footer.
- Build the Home page with the student-focused introduction, trust points, learning pathways, advantages, course previews, and contact preview.
- Build the About page with institute introduction, mission, vision, offerings, reasons to choose the institute, and contact prompt.
- Group the full course catalogue into Programming, Cloud & DevOps, Office Tools, Business Tools, and Technical categories.
- Add testimonial cards with ratings and slider controls.
- Add a training gallery with image zoom and an accessible full-screen preview.
- Add the supplied contact information and a client-side contact form with clear validation and success feedback.

## Visual direction
- Use a white/off-white canvas with navy navigation and footer, plus blue accents only for actions and highlights.
- Use premium compact cards, controlled shadows, generous spacing, and rounded 12–16px corners.
- Use relevant generated student and classroom imagery rather than placeholders.
- Add restrained fade, slide, stagger, and hover motion with reduced-motion support.
- Preserve readability and easy navigation across phone, tablet, and desktop sizes.

## Technical details
- Keep the existing TanStack routing structure and create one route file per page.
- Add reusable site shell, page heading, course, contact, gallery, and testimonial patterns.
- Centralize colors, typography, shadows, radius, and animation timing in the global design tokens.
- Use semantic links for phone, email, and navigation; ensure labels, focus states, image text alternatives, and keyboard controls are included.
- Verify the finished site with the development build and browser checks at desktop and mobile widths.

## Scope note
The contact form will provide complete in-page validation and confirmation. Sending submissions externally requires a mail service or connected backend and is not included in this frontend build.
